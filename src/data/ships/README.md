# data/ships/ - Ship Definitions & Data

Ship-specific data and configurations for different ship types and classes.

## Overview

This directory contains data files for:

- Ship class definitions
- Default loadouts
- Performance characteristics
- Visual properties

## Usage

Ship data is used by:

- Game initialization for spawning ships
- AI systems for behavior selection
- Rendering for model selection
- UI displays for player information
- Balance calculations for difficulty
