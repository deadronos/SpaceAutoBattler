# Reports (Generated Snapshots)

This folder contains point-in-time reports and analyses that were generated during earlier iterations of the project.

- These files are **not maintained** and may include **stale file paths**, **outdated module names**, or inline citation markers like `【F:...】` that do not map cleanly to the current repo.
- Treat them as historical context and idea backlogs, not as a source of truth for the current implementation.

For current, maintained documentation, prefer:

- `docs/app-simulation-flow.md`
- `docs/core_api_summary.md`
- `docs/postprocessing-pipeline.md`
- `memory/*` (especially `memory/systemPatterns.md`, `memory/core-gameState.md`, `memory/core-systems.md`)
