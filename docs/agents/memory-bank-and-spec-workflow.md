# Memory bank + spec-driven workflow

## When you’re doing non-trivial work

- Prefer the spec-driven loop described in `.github/instructions/spec-driven-workflow-v1.instructions.md`.
- Track work in the Memory Bank described in `.github/instructions/memory-bank.instructions.md`.

## Memory Bank expectations

- Store task files in `memory/tasks/`.
- Update progress as you work so future agents can pick up where you left off.

## Useful starting points

- Current active context: `memory/activeContext.md`
- Current progress log: `memory/progress.md`
- Task index: `memory/tasks/_index.md`
