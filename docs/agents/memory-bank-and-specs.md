# Memory Bank & Spec Workflow

## Canonical vs. Historical Docs

- **Canonical agent instructions**: `AGENTS.md` and `docs/agents/*` are the primary, maintained entrypoints for how to build, test, and contribute to this repository.
- **Historical & task context**: `memory/` and `spec/` hold design/task logs and older architectural snapshots. Treat them as historical reference unless actively working on a tracked task—always verify file paths, symbols, and scripts against the current codebase.
